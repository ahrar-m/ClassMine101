## Welcome to the Showcase

This site is built to provide a **100% complete visual reference** for every feature, Markdown extension, UI component, and plugin provided by **Material for MkDocs**. 

> [!TIP]
> **Source Code Hiding Policy**: All raw Markdown source code blocks across every page on this site are **hidden by default** inside collapsible details drawers. Click **"View Source Markdown"** below any visual example to reveal the exact raw syntax!

### Quick Feature Highlights

| Feature Category | Enabled Tools & Extensions | Key Capabilities |
| :--- | :--- | :--- |
| **UI Components** | `admonition`, `attr_list`, `md_in_html`, `pymdownx.tabbed` | Grid Cards, 12 Admonition Types, Linked Tabs |
| **Code & Math** | `pymdownx.highlight`, `pymdownx.arithmatex` | Line Highlights, Code Annotations, MathJax LaTeX |
| **Diagrams** | `pymdownx.superfences` + Mermaid.js | Flowcharts, Sequence, ERD, Mindmap, Gantt, Pie |
| **Extensions** | `pymdownx.keys`, `pymdownx.tasklist` | Keyboard Shortcuts, Interactive Checkboxes, Footnotes |
| **Navigation** | `navigation.tabs`, `navigation.instant` | Sticky Tabs, Instant Page Loads, Fast Search |
