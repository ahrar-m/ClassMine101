## Detailed Walkthrough

### 1. Overview & Standard Form

A **Quadratic Equation** in a single variable $x$ is a polynomial equation of degree **2**. It is expressed in **Standard Form**:

$$ax^2 + bx + c = 0$$

where $a, b, c \in \mathbb{R}$ and $a \neq 0$.

### 2. Solving by Factorization

If $ax^2 + bx + c = 0$ can be factored into $(px + q)(rx + s) = 0$, then by the Zero Product Property, either $px + q = 0$ or $rx + s = 0$.

### 3. Quadratic Formula & Discriminant

The roots are given by:

$$x = \frac{-b \pm \sqrt{D}}{2a} \quad \text{where } D = b^2 - 4ac$$

- If $D > 0$: Two distinct real roots.
- If $D = 0$: Two equal real roots ($x = -b / 2a$).
- If $D < 0$: No real roots (Complex conjugate roots).
